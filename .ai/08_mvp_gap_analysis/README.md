# MVP gap analysis

Đối chiếu phạm vi bài với code hiện tại. Cập nhật khi đóng một khoảng trống.

Đã có trong code: CRUD sách và danh mục ở mức form, bạn đọc, phiếu mượn nhiều dòng, trả một phần, hủy, chính sách phí, thanh toán, miễn giảm, báo cáo quá hạn, seed dữ liệu.

Chưa có, nếu bài yêu cầu thì ghi vào đây trước khi code:

- Đăng nhập và vai trò.
- Sửa hoặc xóa sách, bạn đọc sau khi đã tạo.
- Tìm kiếm, phân trang.
- Biên lai in.
- Đóng gói và chạy ngoài máy dev.

Mỗi gap: tiêu chí chấp nhận, file sẽ đụng, test cần có.
