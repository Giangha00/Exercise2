# ADR

Architecture Decision Record. Một quyết định một file `NNNN-tieu-de.md`.

Mẫu:

```markdown
# NNNN. Tiêu đề

## Bối cảnh

## Quyết định

## Hệ quả
```

Quyết định đang có trong code, chưa tách file riêng: schema do Flyway, Hibernate chỉ validate, web dùng MVC và Thymeleaf, phí tính trong `FineCalculationService`.
